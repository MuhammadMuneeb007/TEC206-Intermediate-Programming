3. Core OOP Concepts

Inheritance

Reuse and specialise. A child class receives behaviour from a parent class.

class Dog(Animal): pass

Polymorphism

Same interface, different behaviour. Different objects implement the same method differently.

animal.speak()

Encapsulation

Protect state. Objects manage their own data through controlled methods.

account.deposit(50)

Abstraction

Hide unnecessary detail. Users work through a simple interface.

payment.pay(100)
