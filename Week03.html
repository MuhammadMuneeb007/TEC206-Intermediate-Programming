Shadowing

Core lessons

          
Use these explanations before or after the interactive activity.

        

      

      

        

          
Built-in namespace

          
Python provides names such as print, len, and sum. Inspect them with:

          import builtins
print(dir(builtins))
print(vars(builtins))
        

        

          
Global namespace

          
Top-level variables, functions, classes, and imports belong to the module's global namespace.

          import math
name = "Alice"

def greet():
    print(name)

print(globals())
        

        

          
Local namespace

          
Parameters and assignments inside a function belong to that function call's local namespace.

          result = "global"

def demo():
    result = "local"
    print(result)
    print(locals())
        

        

          
Enclosing namespace

          
An outer function's local binding becomes enclosing when accessed from a nested function.

          def outer():
    customer = "Alice"

    def inner():
        print(customer)

    inner()
        

        

          
global

          
Use global when assigning to a module-level binding from inside a function.

          value = 10

def change():
    global value
    value = 20
        

        

          
nonlocal

          
Use nonlocal when assigning to a binding in the nearest enclosing function.

          def outer():
    value = 10

    def inner():
        nonlocal value
        value = 20
